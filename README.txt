BET DASHBOARD 2.0 — GitHub Pages

HOW TO PUBLISH
1. Download and extract BET-DASHBOARD-2.0-GITHUB.zip.
2. Open your GitHub repository.
3. Upload index.html (and this README if you want) to the repository root.
4. In Settings > Pages, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Open the Pages URL GitHub provides.

NOTES
- This is a responsive static HTML dashboard. It needs no build step, server, or API key.
- The sample bets, balances, scores and match statistics are demonstration data.
- The New Bet form adds rows in the current browser session only. It does not persist after a refresh.
- Live scores, bookmaker account data, wallet transactions, and real betting settlement are not connected.
- The Filter button filters the table; search searches the bet rows.
